# 智慧宿舍管理系统 v2.0

## 系统简介

智慧宿舍管理系统是一款专为企业、学校、园区设计的宿舍管理解决方案。系统采用现代化的Web技术栈，提供完整的宿舍管理功能，包括学生/员工入住管理、费用管理、报修管理、通知公告等模块。

## 主要功能

### 1. 学生/住户管理
- 学生信息录入、编辑、删除
- 批量导入导出（支持Excel）
- 照片管理
- 入住/退宿管理
- 多维度查询筛选

### 2. 宿舍管理
- 楼栋管理
- 宿舍信息管理
- 床位分配
- 入住率统计
- 设施配置管理

### 3. 费用管理
- 住宿费管理
- 水电费管理
- 网费管理
- 费用统计报表
- 缴费记录查询

### 4. 报修管理
- 在线报修
- 工单分配
- 维修进度跟踪
- 维修评价
- 费用核算

### 5. 通知公告
- 公告发布
- 置顶功能
- 分类管理
- 阅读统计

### 6. 系统管理
- 用户权限管理
- 操作日志
- 数据备份
- 系统配置

## 技术特点

- **高性能**: 数据库连接池、查询优化、缓存机制
- **高安全**: CSRF防护、SQL注入防护、XSS防护
- **易用性**: 响应式设计、现代化UI、流畅交互
- **可扩展**: 模块化设计、插件化架构

## 系统要求

### 服务器要求
- Windows 7/8/10/11 或 Windows Server 2012+
- Linux (Ubuntu 18.04+, CentOS 7+)
- Python 3.8+
- MySQL 5.7+ / MariaDB 10.2+
- 内存: 2GB+
- 硬盘: 10GB+

### 客户端要求
- 现代浏览器 (Chrome, Firefox, Edge, Safari)
- 分辨率: 1280x768 或更高

## 安装步骤

### 方式一：使用安装包（推荐）

1. 下载安装包 `智慧宿舍管理系统_Setup.exe`
2. 双击运行安装程序
3. 按向导完成安装
4. 安装完成后，桌面会生成快捷方式
5. 双击快捷方式启动系统

### 方式二：手动安装

1. 安装 Python 3.8+
2. 安装 MySQL 5.7+
3. 创建数据库:
   ```bash
   mysql -u root -p < database_init.sql
   ```
4. 安装依赖:
   ```bash
   pip install -r requirements.txt
   ```
5. 启动系统:
   ```bash
   python app_new.py
   ```
6. 浏览器访问: http://localhost:8080

## 使用说明

### 快速开始

1. 登录系统
2. 进入"楼栋管理"添加楼栋
3. 进入"宿舍管理"添加宿舍
4. 进入"学生管理"添加学生
5. 开始使用各项功能

### 数据导入

系统支持Excel批量导入学生信息：

1. 下载导入模板
2. 按模板格式填写数据
3. 进入"批量导入"页面
4. 上传Excel文件
5. 系统自动校验并导入

### 数据备份

建议定期进行数据备份：

1. 进入"系统管理" -> "数据备份"
2. 点击"立即备份"
3. 下载备份文件保存

## 常见问题

### Q: 忘记管理员密码怎么办？
A: 可以通过数据库直接修改密码字段，或使用密码重置工具。

### Q: 如何修改端口号？
A: 编辑 `config.py` 文件，修改 `PORT` 配置项。

### Q: 如何配置外网访问？
A: 修改 `config.py` 中的 `HOST` 为 `0.0.0.0`，并确保防火墙开放对应端口。

### Q: 支持哪些浏览器？
A: 支持 Chrome 90+, Firefox 88+, Edge 90+, Safari 14+。
